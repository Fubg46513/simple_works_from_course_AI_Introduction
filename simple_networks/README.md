# 50*50灰度图猫狗二分类神经网络
## 文件组成
	整个project的制作过程都比较随意，没有一个大的方向，常常是想到什么看到什么就做了一些什么内容，很多py文件还是可以打包一下的，但是由于完成过程比较碎片化，就没有重新进行整合，之后需要调用也还是可以照搬。
	Animal Images文件夹下为提供好的数据集，分为猫狗两个label分别存储。
	fig文件夹下存储了在模型训练过程中的loss曲线与acc变化情况，及以model2为例进行的卷积层可视化。命名方式为“模型_epoch”，“模型_卷积层数”
	hook文件夹相当于是猫的部分图+狗的全部图，目的是看看模型筛选效果如何，将model2的最后一层64->2中的输入进行提取，后对所有图像均进行提取后比较向量相似度最高的图像，并对其进行查看。
	models文件夹下存储的model1~3对应了train.py训练得到的模型，均为epoch=10得到的模型。
	**test文件夹下两个路径分别对应进行测试集导入。**
	wasted文件夹为测试中保存的数据，但没有用于写报告或者代码中。
## 运行方式
	models文件夹下已经有model1~3.pth，将相应的测试数据以一个文件夹下对应两个label(cats,dogs)的形式存储，修改test_path后，运行test_fun.py即可进行模型评估。
